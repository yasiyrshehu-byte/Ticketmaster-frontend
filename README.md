# TicketWAVES front-end replacement

Upload these files to the GitHub Pages repository root:
- index.html
- style.css
- script.js

The ticket-detail front is a static school/demo UI with the requested artwork area, sharp-cut black information card, blue View Tickets button, Tickets/Extras tabs, order details, ticket cards, map/actions, Extras, and a separate View Ticket screen with a visual barcode simulation.
